# Contributing to CampusPay

Thank you for considering contributing to CampusPay!

## Pull Request Process

1. Fork the repository on GitHub.
2. Create a feature branch: `git checkout -b feature/my-new-feature`.
3. Ensure strict TypeScript checks and zero lint errors: `npm run build`.
4. Commit your changes with meaningful commit messages.
5. Push your branch and submit a Pull Request to `origin/main`.

## Coding Standards
- Use TypeScript strict mode (no `any` types).
- Maintain glassmorphic dark-mode design rules (`#09090B`, `#18181B`, `#6D28D9`, `#8B5CF6`).
- Follow Feature-Based Architecture under `features/`.
